Direct image only: up to three new paid attempts (four total), 15 seconds apart. EACH retry requires the preceding attempt to end with an unusable completed scene below 10,000 reported thinking + output tokens, or a start conclusively never received. Every attempt bills its own input and generation and consumes a request slot. Unknown or partial usage, interrupted calls and provider errors do not retry.

Thinking is how much Argon reasons before answering: higher can place parts more accurately but bills more output tokens. Detail is how many objects Argon aims for: Standard 48–96 (subject) or 80–120 (full scene), High up to 150, Maximum targets 180–230 full-scene objects, up to 240. Every detail level uses the selected token budget (32,768 by default); an answer cut off at it keeps every object it finished. High and Maximum need the 65,536 budget: at 32,768 every run came back empty, while at 65,536 they returned 106 to 153 objects (2026-10-23). Argon Previs has no budget choice, so use Standard detail there.

All options use your existing server-side Gemini API key. Argon Previs uses Gemini 3.5 Flash-Lite to analyze the reference JPEGs quickly, then Gemini 4 Argon generates editable geometry from the visual description using text-only background execution for AE/GLB export and eventual Runway video-to-video. It uses up to two potentially billable calls and two request slots. Google stores the visual description and generated scene in the Argon background interaction, not the original images. It may take several minutes; Google bills input and thinking/output tokens. No geometry saves until you accept.

Argon Direct image (experimental) sends the same reference JPEGs straight to Gemini 4 Argon, so Argon observes the frames itself. Each attempt is one synchronous request held by Cloudflare for up to 12 minutes while the editor polls, at either token budget. One potentially billable base call and one request slot per attempt; enabling automatic retries permits at most four base attempts (one initial plus three retries), plus two separately billable Add Detail calls when enabled. The Cloudflare job keeps the images only until Argon answers and the result for 24 hours; Google is asked not to store either. Nothing falls back automatically; Argon Previs remains the proven path. With Full environment selected, the same single call rebuilds the whole frame (background buildings, ground, roads, vegetation, street furniture and lighting) instead of the main subject; it never runs the four Flash passes.
